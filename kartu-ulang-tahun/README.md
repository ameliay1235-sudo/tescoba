# Kartu Ulang Tahun 💖

Kartu ucapan ulang tahun interaktif (HTML + CSS + JavaScript) dengan animasi teratai dan hati yang melayang.

## Cara mengganti nama
Buka `index.html`, cari baris berikut, lalu ganti `"Kamu"` dengan nama penerima:

```js
var NAMA="Kamu";
```

## Hosting dengan GitHub Pages
1. Unggah semua file ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1-2 menit, kartu bisa dibuka di `https://USERNAME.github.io/NAMA-REPO/`.
